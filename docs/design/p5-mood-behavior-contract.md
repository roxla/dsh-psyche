# P5-0 心情行为契约

- 状态：P5-0 冻结稿（2026-11-14）
- 定位：把 Global Mood / Contact Affect 映射为少量确定性行为档位，只改变表达，不改变事实与权限
- 关联：`p5-projection-composition.md`、`p5-mood-behavior-contract.md`

## 1. 边界

- 心情可以影响：表达长度、语气、主动性偏好、解释详略、群聊参与倾向。
- 心情不可以影响：事实判断、证据标准、工具调用标准、权限、是否回应用户的明确请求、是否遵守安全与隐私规则。
- 心情变化不等于人格改变；人格定义心情变化的表达边界。

## 2. 输入

- Global Mood：33 维状态经衰减后的有效值；
- Contact Affect：warmth / tension / hurt / missing / irritation；
- 不使用原始数值直接生成 Prompt，只使用档位。

## 3. 档位

固定三档：`reserved / balanced / expressive`。

- 映射由固定权重、阈值、判定顺序组成，参数版本化为 `mood-behavior-v1`；
- 具体权重与阈值在 P5-4 实现前以表格冻结，运行时不可调；
- 无有效 Mood 或读取失败 → `balanced`；
- 档位不写入数据库，不改变 Mood 状态，不产生诊断事件。

## 4. 档位稳定（滞回）

为避免衰减导致连续两轮跳档：

- 进入 `expressive`：score ≥ +0.35；退出：score ≤ +0.25；
- 进入 `reserved`：score ≤ -0.35；退出：score ≥ -0.25；
- 两档之间切换至少保持 1 个完整 Turn；
- 边界值按 `>=` / `<=` 固定，测试覆盖 0.249/0.25/0.35/0.351；
- 时钟与衰减使用与 Mood 投影一致的快照，不重复计算。

## 5. 优先级（硬规则）

1. 宿主安全规则；
2. 用户明确指令；
3. 事实、证据与 Scope/隐私纪律；
4. 工具与权限标准；
5. 心情表达。

心情永远不能把 1–4 降级。做不到时宁可 `balanced`，不能为了“表现情绪”而违反规则。

## 6. 允许与禁止

| 维度 | 允许 | 禁止 |
|---|---|---|
| 回复长度 | 开心更愿意展开，疲惫相对简短 | 因疲惫省略必要事实或安全提示 |
| 语气 | 热情 / 平静 / 谨慎 / 活跃 | 伪造情绪理由、改变事实判断 |
| 主动性 | 调整**已授权**主动联系候选的优先级 | 绕过 Consent、静默、限额、审批 |
| 群聊参与 | 在可选回复场景调整参与倾向 | 跳过确定性必须回复的准入规则 |
| 对 Contact | 结合长期 Affinity 与短期 Affect 调整亲疏表达 | 因好感泄露其他人的记忆 |
| 解释 | 更简洁或更审慎 | 降低工具、证据、校验标准 |

## 7. 投影

- Context 名称：`psyche-mood-behavior`（可与现有 `psyche-mood-tone` 合并，但只能有一个出口）。
- 内容：一行档位提示，≤ 80 字符，不含数值、不含“你必须”式命令。
- 示例（示意，不是固定文案）：“当前表达倾向：简洁克制；不改变事实与权限。”
- 与 Mood 语气块同时存在时，由投影组合器去重，只保留一个 Mood 出口。

## 8. 验收

模块层：

- 固定输入下档位确定；边界与滞回断言；
- 三档下事实内容一致，仅长度/语气/主动性差异；
- 心情不得导致拒答、省略关键事实、改变工具选择；
- 无状态/读取失败 → `balanced`；
- 档位切换最小驻留 Turn 生效。

隔离 Host：

- 三档投影都进入最终 Prompt；
- 总预算内只出现一个 Mood 出口；
- 卸载重载无残留。

行为层：

- 固定模型、temperature 0、同问题重复多次，比较长度/主动性分布；
- 不把单次输出差异当作确定性证据。
