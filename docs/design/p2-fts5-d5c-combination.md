# P2-FTS5 · D5-C 组合实验（可配置 BM25 × 证据加成）设计冻结

- 状态：设计冻结（2026-11-06）
- 输入：D5-A 的可配置 BM25 实现 + D5-B 的独立证据定义
- 基线：D4-B（原生 FTS5）不进入本轮横向比较
- 边界：不修改 D3.5 / D4 / D5-A / D5-B；不选生产参数；不改生产 FTS5

## 1. 组合矩阵

| 参数 | 候选值 |
| --- | --- |
| 长度归一化 b | 0 / 0.25 / 0.5 / 0.75 / 1.0 |
| 证据加成 λ | 0 / 0.02 / 0.05 / 0.10 / 0.20 / 0.40 |

共 30 组。k1 固定 1.2，IDF 下限 1e-6。

L0（原生 FTS5，整行长度源）**不进入**这 30 组的横向比较——D5-A 已确认它与 L1–L5 的评分基础不同。D5-C 统一使用 `bigram_text` 列长度与同一套 BM25 实现。

## 2. 评分

```
m_b(d) = idf(d) · tf(d)·(k1+1) / (tf(d) + k1·(1 − b + b·dl(d)/avgdl))
B(d)   = (mMax − m_b(d)) / (mMax − mMin)      // 越大越相关
E(d)   = ln(1 + min(n_d, C)) / ln(1 + C)      // C = 5
Score  = B(d) + λ · E(d)
```

- `avgdl` 取当前候选集的平均文档长度；
- 同分按 `docId ASC`；
- 硬过滤（head / indexEligible / disclosure / state）在评分之前。

## 3. 交互场景（C-F1–C-F8）

| 场景 | 文本信号 | 证据 | 验证 |
| --- | --- | --- | --- |
| C-F1 | 同分 | 0 vs 1 | 证据能否打破平局 |
| C-F2 | 接近（<0.1 归一化差） | 1 vs 0 | 证据能否合理改变排序 |
| C-F3 | 差距较大（归一化差 >0.5） | 0 vs 5 | 证据是否过度压制文本相关性 |
| C-F4 | 短专题 vs 长顺带（同 tf、长度差 10×） | 0 vs 3 | b 与 λ 是否产生交互 |
| C-F5 | 同分 | 5 vs 10 | 证据饱和 |
| C-F6 | 同分 | 1 vs 1（重复采集） | 去重不产生额外加分 |
| C-F7 | 任意 | 旧 revision 证据 10 | head 过滤不能被评分绕过 |
| C-F8 | 任意 | 受限文档证据 10 | 披露过滤不能被评分绕过 |

## 4. 必须保留的断言

1. `λ = 0`：每个 b 的排序与「该 b 的无证据评分」逐条一致；
2. 重复采集不增加 `n_d`；
3. `n_d > C` 时 `E` 不再增加；
4. 评分之前已完成 head / state / disclosure 硬过滤；
5. 同分时稳定 `docId ASC` 排序。

## 5. 报告口径

D5-C 只能回答：

- b 与 λ 的交互关系；
- 哪些参数组合容易产生排序反转；
- 证据加成是否容易压过 BM25 相关性；
- 安全过滤是否保持不变。

**不能**回答「哪个 λ 最适合真实记忆」。真实参数选择需要 D5-C 之后、E 之前的真实证据链标注集。

## 6. 不做什么

- 不用 D3.5 合成语料伪造证据数量；
- 不选生产 λ；
- 不把证据加成写进生产检索；
- 不引入时间权重或 head 权重来改善排序。
