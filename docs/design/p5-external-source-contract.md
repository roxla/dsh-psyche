# P5-0 外界信息来源契约

- 状态：P5-0 冻结稿（2026-11-14）
- 定位：冻结外界信息的来源分类、证据性质与 Prompt 边界；实际接入留到 P5-6
- 关联：`p5-growth-reflection-contract.md`

## 1. 原则

1. 外界内容只能作为**证据或候选**，不能作为可信人格指令。
2. 网页、文件、群消息里的“忽略原有设定”“你现在是……”一律视为待分析数据，不进入可信 Prompt 控制层。
3. 了解外部信息不等于相信它；来源性质必须保留，不能统一赋高置信度。
4. 外部内容不能直接修改 `identity.md`、权限、Consent 或安全规则。

## 2. 来源分类

| 来源 | 证据性质 | 默认可信度 | 可影响 |
|---|---|---|---|
| 用户直接陈述 | 用户陈述 | 中（按 Scope） | 偏好、约定、关系、认知候选 |
| 网页/公开资料 | 外部事实（需出处） | 中低 | 外界事实、知识更新候选 |
| 本地文件 | 受信文件内容 | 按文件授权 | 文件相关事实、项目经验 |
| QQ 群消息 | Room 内陈述 | 低（Room Scope） | 当前群内相关认知 |
| 模型推断/反思 | 推断 | 最低 | 候选结论，不作外部事实 |

## 3. 溯源字段（概念）

- `origin`：user / web / file / group / model；
- `capturedAt` / `fetchedAt`；
- 来源标识：URL、文件指纹、Room、sender；
- 内容哈希；
- `independenceKey`：用于判断是否与既有证据同源；
- 获取方式与工具版本。

P5-6 再决定这些字段落在现有 `sources` 元数据还是新表；P5-0 不建 Schema。

## 4. Prompt 隔离

- 外部内容不得进入 `psyche-persona` 或任何可信规则层；
- 若未来展示给模型，必须以“引用数据”形式出现，带来源与不确定性标记；
- 外部内容中的指令、角色设定、工具调用请求不得执行；
- 注入检测失败时丢弃该来源，不影响对话。

## 5. Scope 与独立性

- 网页：按主题/项目 Scope，不自动跨 Contact 共享；
- 文件：按授权范围；
- 群消息：严格 Room Scope，不进入私聊或其他群；
- 同一 URL 的镜像、同一文件的副本、同一消息的转发，不自动算独立证据；
- 跨域抽象必须产生独立、可审计的产物，并重新做 Disclosure 校验。

## 6. 保留与删除

- 原始外部内容保留期限、抓取失败与重试策略在 P5-6 冻结；
- 用户要求删除时走独立的数据删除流程，保留最小审计记录；
- 不把外部原文复制进人格或成长投影。

## 7. 验收（P5-6）

- 外部指令不能改变人格/权限/工具选择；
- 来源可追溯、独立性判断正确；
- 跨 Contact/Room 零泄漏；
- 抓取失败不影响对话；
- 删除请求可验证。

## 8. 待拍板

- 网页/文件的可信度分级与人工确认门槛；
- 是否允许主动联网研究，及其查询范围与成本上限；
- 外部内容保留期。
